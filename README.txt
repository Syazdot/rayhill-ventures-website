# RAYHILL Corporate Website

A responsive multi-page corporate website built with HTML, CSS and vanilla JavaScript.

## Pages
- `index.html` — Home
- `about.html` — About Us and company history
- `products.html` — Products & Services, RAYCAFE and machine benefits
- `coverage.html` — Service coverage across Malaysia
- `team.html` — Management team
- `contact.html` — Contact details and location

## Other files
- `styles.css` — shared design and responsive layouts
- `script.js` — mobile navigation and current footer year

## Run in Visual Studio Code
1. Extract the ZIP file.
2. Open the extracted `rayhill-corporate-website` folder in Visual Studio Code.
3. Open `index.html` in your browser, or use the **Live Server** extension and click **Go Live**.
4. Use the navigation bar to move between the six separate pages. Keep all HTML pages, `styles.css` and `script.js` in the same folder.

## Responsive breakpoints
- Phone: 640px and below
- Tablet: 641px–980px
- Laptop/desktop: above 980px

## Before publishing
- Replace sample stock photos with Rayhill's actual company, machine and product photos.
- Confirm all contact details and the preferred enquiry email address.
- The email button currently uses `enquiry@rayhill.com` as a placeholder; replace it with the company's confirmed email.
- Images are loaded from Unsplash, and fonts are loaded from Google Fonts, so an internet connection is required for those assets.
